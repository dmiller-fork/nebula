- 1st: The title slide should contain the title of your project and the names of the team members

- 2nd slide: outline of the presentation, e.g.:
	- project problem/task/question
	- dataset
	- algorithm
	- results
	- conclusion

- 3rd: project topic explanation

- 4th: Introduction with the dataset and a list of what is done

- 5th: explain/teach the implemented algorithm

- 6th: the results /evaluation

- The last slide: conclusion and an overview of what was presented (~ similar to the 2nd slide), and recommendations for future
work and/or improvements
